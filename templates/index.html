الأسئلة الشائعةFAQ

أسئلة شائعة حول فحص الروابطFrequently asked questions about link scanning

ما هو فاحص اللينكات؟What is Link Checker?
منصة مجانية بالكامل تساعدك على تقييم الروابط والملفات وكشف مؤشرات الخطر المحتملة قبل التعامل معها.A completely free platform that helps you assess links and files and spot potential risk indicators before you interact with them.
كيف أعرف أن الرابط خطير؟How do I know a link is dangerous?
نفحص غياب HTTPS وامتداد الدومين وبنيته والكلمات الشائعة في الاحتيال وانتحال أسماء العلامات، ثم نجمع نقاط المؤشرات في نسبة خطر واحدة.We check for missing HTTPS, the domain extension and structure, common scam words and brand impersonation, then add the indicator points into a single risk percentage.
هل يمكن فحص الصور والملفات؟Can images and files be scanned?
نعم، يمكنك رفع ملف أو صورة ومتابعة حالة الفحص ونتيجته من قسم «فحص ملف أو صورة».Yes. Upload a file or image and follow the scan status and result from the “File or image scan” section.
هل الفحص يضمن أمان الملف بنسبة 100%؟Does a scan guarantee a file is 100% safe?
لا. النتيجة مؤشر يساعدك على اتخاذ القرار، وغياب المؤشرات لا يعني الأمان المطلق، فتعامل مع المصادر المجهولة بحذر دائماً.No. The result is an indicator that helps you decide; no indicators doesn't mean absolute safety, so always be careful with unknown sources.
هل يتم الاحتفاظ بالملفات المرفوعة؟Are uploaded files kept?
لا. يُقرأ الملف في الذاكرة أثناء الفحص فقط، ولا يُحفظ بعد انتهائه ولا يُشغَّل أبداً. وعند تفعيل VirusTotal يُرسَل الهاش (SHA-256) فقط وليس الملف نفسه.No. The file is read in memory during the scan only, is not kept afterwards and is never executed. If VirusTotal is enabled, only the file's SHA-256 hash is sent, not the file itself.
